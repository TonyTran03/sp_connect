Formula Reference

NORMAL & SAMPLING DISTRIBUTIONS

Type 1: Linear combinations / normal sums

\[E(aX+bY)=aE(X)+bE(Y)\] \[\operatorname{Var}(aX+bY) =a^2\operatorname{Var}(X)+b^2\operatorname{Var}(Y) +2ab\operatorname{Cov}(X,Y)\] Independent \(\Rightarrow \operatorname{Cov}(X,Y)=0\).

Type 2: Sampling distributions of means

\[E(\bar X)=\mu,\qquad \operatorname{Var}(\bar X)=\frac{\sigma^2}{n},\qquad SE(\bar X)=\frac{\sigma}{\sqrt n}\] \[E\!\left(\sum X_i\right)=n\mu,\qquad SD\!\left(\sum X_i\right)=\sqrt n\,\sigma\]

Type 3: Binomial normal approximation / CLT

\[X\sim\operatorname{Bin}(n,p),\qquad E(X)=np,\qquad SD(X)=\sqrt{np(1-p)}\] \[Z=\frac{X-np}{\sqrt{np(1-p)}}\] For CLT sums/averages, first find the mean and standard error of the quantity being standardized.

CONFIDENCE INTERVALS

Type 4: Mean CI: population SD known

\[\boxed{\bar x\pm z_{\alpha/2}\frac{\sigma}{\sqrt n}}\] \[ME=z_{\alpha/2}\frac{\sigma}{\sqrt n}, \qquad n=\left(\frac{z_{\alpha/2}\sigma}{ME}\right)^2\] Round required sample size up.

Type 5: Mean CI: population SD unknown

\[\boxed{\bar x\pm t_{\alpha/2,\,df}\frac{s}{\sqrt n}} \qquad \boxed{df=n-1}\]

Type 6: Proportion CI / margin of error / sample size

\[\boxed{ \hat p\pm z_{\alpha/2} \sqrt{\frac{\hat p(1-\hat p)}{n}} }\] \[ME=z_{\alpha/2} \sqrt{\frac{\hat p(1-\hat p)}{n}}\] \[n= \frac{z_{\alpha/2}^2\hat p(1-\hat p)}{ME^2}\] If no prior \(\hat p\) is available for planning, use \(0.5\).

Type 7: Meaning of confidence level

A \(100(1-\alpha)\%\) confidence procedure captures the true parameter in approximately \[100(1-\alpha)\%\] of repeated samples.

HYPOTHESIS TESTING

Type 8: Writing hypotheses / choosing the tail

\[H_a:\mu>\mu_0 \Rightarrow \text{right tail},\qquad H_a:\mu<\mu_0 \Rightarrow \text{left tail}\] \[H_a:\mu\neq\mu_0 \Rightarrow \text{two tails}\] Equality belongs in \(H_0\).

Type 9: One-sample mean: z-test

Known population SD: \[\boxed{ z=\frac{\bar x-\mu_0}{\sigma/\sqrt n} }\]

Type 10: One-sample mean: t-test

Unknown population SD: \[\boxed{ t=\frac{\bar x-\mu_0}{s/\sqrt n} } \qquad \boxed{df=n-1}\]

Type 11: One-proportion z-test

\[\boxed{ z= \frac{\hat p-p_0} {\sqrt{p_0(1-p_0)/n}} }\] Use the null value \(p_0\) in the test standard error.

Type 12: Paired t-test

Define the within-pair difference first: \[d_i=X_{1i}-X_{2i}\] Then \[\boxed{ t= \frac{\bar d-\mu_{d,0}} {s_d/\sqrt n} } \qquad \boxed{df=n-1}\] Here \(n\) is the number of pairs.

Type 13: Two independent means

\[\boxed{ t= \frac{(\bar x_1-\bar x_2)-\Delta_0} {\sqrt{s_1^2/n_1+s_2^2/n_2}} }\] Welch degrees of freedom: \[df\approx \frac{(s_1^2/n_1+s_2^2/n_2)^2} {\frac{(s_1^2/n_1)^2}{n_1-1} +\frac{(s_2^2/n_2)^2}{n_2-1}}\] If the course explicitly pools equal variances, use its pooled formula and \(df=n_1+n_2-2\).

Type 14: Two proportions

For testing \(H_0:p_1=p_2\), \[\hat p_{\text{pool}}=\frac{x_1+x_2}{n_1+n_2}\] \[SE_0= \sqrt{ \hat p_{\text{pool}}(1-\hat p_{\text{pool}}) \left(\frac1{n_1}+\frac1{n_2}\right) }\] \[\boxed{ z=\frac{\hat p_1-\hat p_2}{SE_0} }\]

ERROR TYPES & TEST LOGIC

Type 15: Type I / Type II errors

\[\text{Type I: reject }H_0\text{ when }H_0\text{ is true}\] \[P(\text{Type I})=\alpha\] \[\text{Type II: fail to reject }H_0\text{ when }H_a\text{ is true}\] \[P(\text{Type II})=\beta,\qquad \text{Power}=1-\beta\]

Type 16: p-value and significance-level decisions

\[\boxed{p\text{-value}<\alpha\Rightarrow\text{reject }H_0}\] \[\boxed{p\text{-value}\ge\alpha\Rightarrow\text{fail to reject }H_0}\]

MIXED REVIEW

Type 17: Recognition: choose the procedure first

Recognition order: \[\boxed{ \text{parameter} \rightarrow \text{one/two sample?} \rightarrow \text{mean/proportion?} \rightarrow z/t? \rightarrow df\text{ if }t }\]
